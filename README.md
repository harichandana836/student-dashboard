# 🎓 Student Dashboard
A simple dashboard to manage and visualize student performance.

## Features
- Add students
- Edit student details
- Delete students
- Search students
- Automatic grade calculation
- Dashboard statistics
- Chart visualization
- Local Storage support

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js
- GitHub Pages
